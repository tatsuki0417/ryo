# ぴぽっち 🥚 ― レトロ育成ペット

ブラウザで育てる、ドット絵のデジタルペット。
「たまごっち」「トモコレ」世代の**懐古心（ノスタルジー）**に刺さる、放置育成ゲームのMVPです。

> **なぜ今これか（市場の狙い）**
> 2026年のネットは「SNS疲れ／アテンション・デトックス」と、
> "2026 is the new 2016" と呼ばれる**懐古回帰**が一等地トレンド。
> たまごっち直撃世代（今の28〜38歳）が可処分所得を持つ大人になり、
> レトロ×やさしい体験にお金と時間を使う土壌ができています。
> ターゲットはこの層＋レトロ好きのZ世代。

---

## 遊び方

1. このフォルダの `index.html` をブラウザで開くだけ（インストール不要）。
2. たまごが数分でかえって「こども」になり、24時間で「おとな」に成長します。
3. `ごはん / あそぶ / そうじ / ねる` でお世話。放置すると空腹・きげんが下がります。
4. **タブを閉じても時間はすすみます**（次に開くと経過ぶんが反映）。
5. `📸 きろくをシェア` で、ペットの姿＋いっしょにいる日数＋今日の一言を
   1枚のカード画像にしてSNSにシェアできます（＝拡散の導線）。

> ローカルで動かすとき、ES Modules を使っているので
> `file://` で開けない場合は簡易サーバー越しに開いてください：
> ```
> python3 -m http.server 8000   →  http://localhost:8000
> ```

## ファイル構成（学習用にわざと役割ごとに分けています）

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み（デバイス・ボタン） |
| `css/style.css` | たまごっち風の見た目。色は `:root` の変数で管理 |
| `js/pixel.js` | ドット絵エンジン。キャラは16×16の文字マスで定義 |
| `js/pet.js` | ペットの状態とルール（空腹・成長・保存など） |
| `js/phrases.js` | 「今日のひとこと」。★ここをAIに差し替え可能 |
| `js/share.js` | シェア用カード画像の生成（バズの仕掛け） |
| `js/game.js` | すべてをつなぐメインループ |

**改造のヒント（学習中の方へ）**
- キャラを増やす → `js/pixel.js` に新しいドット絵を足す
- セリフを増やす → `js/phrases.js` の配列に追記
- 難易度を変える → `js/pet.js` の `CONFIG` の数値を変える
- 色を変える → `css/style.css` の `:root` の変数

## ロードマップ

**Phase 1（このMVP）** ✅
1体を育てる／放置成長／シェアカード。サーバー不要・0円で公開可能。

**Phase 2 ― バズ強化**
- キャラのバリエーション追加（かえるたびに種類が変わる）
- 成長分岐（お世話の仕方で見た目が変わる＝コレクション欲）
- BGM・効果音（あの「ピピッ」音）

**Phase 3 ― トモコレ路線（AI）**
- 複数キャラを住まわせ、**AIがキャラ同士の会話を自動生成**
- 面白い会話をスクショしてシェア → 拡散の主戦力に
- ※このとき初めてサーバー＋AI APIが必要（コスト設計に注意）

## マネタイズ設計

| 段階 | 手法 | 補足 |
|---|---|---|
| 1. 集客 | 完全無料で公開しユーザーを集める | まずは拡散最優先 |
| 2. 少額課金 | 着せ替え・背景・レア種のたまご（買い切り） | `:root` の色替えで実装が軽い |
| 3. サブスク | 複数キャラ＋AI会話（Phase 3）を月額に | 継続課金の柱 |
| 4. コラボ/グッズ | 人気が出たらキャラのLINEスタンプ・グッズ | 二次展開 |

まずは Phase 1 を公開し、**シェア数・再訪率**という「バズの脈」を見てから
Phase 2/3 に投資するのが、個人開発でリスクを抑える定石です。

## 公開（デプロイ）方法

静的サイトなので無料でそのまま公開できます。
- **GitHub Pages**：このリポジトリの Settings → Pages で公開
- **Netlify / Vercel / Cloudflare Pages**：フォルダをドラッグ＆ドロップ

App Store審査が不要なので、**その日のうちに拡散テスト**ができます。
