# キラキラCut 🎬✨

TikTok向けの**縦型（9:16）動画エディター**。女子Vlog・買い物紹介系のショート動画をスマホでかんたんに編集できる Web アプリ（PWA）です。

## できること

- 📱 **縦型9:16プレビュー** — TikTokと同じ比率で編集
- ✂️ **カット / トリミング** — いらない部分を削って、複数クリップを並べ替え
- 🅣 **かわいいテロップ** — ポップ / ゆめかわ / 手書き風 / 値段タグ / ネオン など。プレビュー上でドラッグして自由に配置、表示タイミングも調整可能
- 🎨 **映える色味フィルター** — キラキラ / ぴんく / カフェ / 透明感 / フィルム / モノクロ
- 🎵 **BGM** — 端末の音源を追加して音量調整
- 💾 **書き出し** — 編集結果を縦型動画ファイルとして保存（プレビューを録画。ブラウザにより webm / mp4）

> スマホのホーム画面に追加すればアプリのように使えます（PWA対応）。

## 技術構成

- Vite + React + TypeScript
- 再生・書き出しはブラウザ標準API（`<video>` / Canvas `captureStream` / `MediaRecorder` / Web Audio）だけで完結。追加の重いライブラリなし

## 開発

```bash
npm install
npm run dev      # 開発サーバー起動
npm run build    # 本番ビルド
npm run lint     # 型チェック
```

## 注意

- 書き出しは端末・ブラウザのコーデック対応に依存します（iOS Safari は制限あり。Chrome推奨）。
- BGMやクリップの著作権にはご注意ください。手持ちの権利がある音源を使ってください。
