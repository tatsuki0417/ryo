# PC フォルダ整理ツール

散らかった PC のフォルダを、**削除せず安全に**階層構造へ整理するスクリプトです。
「削除しても良さそう」なファイルは、消さずに新規の `_削除候補` フォルダへまとめます。

## 特徴（安全設計）

- 🚫 **削除は一切しません。** すべて「移動」だけです。
- 👀 **既定はドライラン**（計画を表示するだけ）。`--apply` を付けて初めて実行されます。
- ↩️ **いつでも元に戻せます。** 実行内容は CSV ログに残り、`--undo` で復元できます。
- 📁 **既存の意味のあるフォルダには触りません。** 空フォルダやコピー・旧版らしい名前のフォルダだけを削除候補に回します。

## 事前準備

Python 3 が必要です（多くの Mac には最初から入っています。Windows は
[python.org](https://www.python.org/downloads/) からインストールし、
インストール時に「Add Python to PATH」にチェックを入れてください）。

インストール確認:

```
python3 --version    # Mac / Linux
python --version     # Windows
```

## 使い方

### 手順 1: まず計画を確認（ファイルは動きません）

```
# Windows の例（デスクトップを整理する場合）
python organize_pc_folders.py "C:\Users\ryo\Desktop"

# Mac の例
python3 organize_pc_folders.py ~/Desktop
```

どのファイルがどのフォルダに移動されるか、削除候補が何かが一覧表示されます。

### 手順 2: 問題なければ実行

同じコマンドに `--apply` を付けます。

```
python organize_pc_folders.py "C:\Users\ryo\Desktop" --apply
```

実行が終わると、整理内容を記録した `organize_log_日付_時刻.csv` が対象フォルダ内に作られます。

### 手順 3: 元に戻したいとき

手順 2 で表示されたログファイルを `--undo` に指定します。

```
python organize_pc_folders.py --undo "C:\Users\ryo\Desktop\organize_log_20260706_101530.csv"
```

すべてのファイルが元の場所に戻り、整理で作った空フォルダも片付けられます。

## 整理のルール

### 種類別フォルダへの振り分け

| フォルダ | 対象の例 |
|----------|----------|
| `書類` | pdf, doc, docx, xls, xlsx, ppt, txt, csv など |
| `画像` | jpg, png, gif, heic, svg など |
| `動画` | mp4, mov, avi, mkv など |
| `音声` | mp3, wav, m4a, flac など |
| `圧縮ファイル` | zip, rar, 7z, tar など |
| `アプリ・インストーラ` | exe, msi, dmg, pkg, apk など |
| `コード` | py, js, html, json など |
| `その他` | 上記に当てはまらないもの |

### `_削除候補` フォルダへまとめるもの

- OS が作る不要ファイル（`.DS_Store`, `Thumbs.db`, `desktop.ini` など）
- 一時・未完了ファイル（`.tmp`, `.crdownload`, `~$…` など）
- 中身が空（0 バイト）のファイル
- 内容がまったく同じ**重複ファイル**（1 つだけ残し、残りを移動）
- 「コピー」「バックアップ」「旧」「(1)」などが名前に付いたファイル・フォルダ
- 空のフォルダ

> ⚠️ あくまで「候補」です。中身を確認してから、本当に不要なものだけ手動で削除してください。

## オプション

| オプション | 説明 |
|-----------|------|
| `--apply` | 実際に移動を実行（付けないと計画表示のみ） |
| `--undo <ログCSV>` | 指定した実行を元に戻す |
| `--old-days N` | N 日以上更新のないファイルも削除候補にする（既定 0＝無効） |
| `--include-hidden` | 隠しファイル・ドット始まりのフォルダも対象にする（既定では触りません） |

## よくある質問

**Q. 間違えて実行してしまいました。**
A. 対象フォルダにできた `organize_log_….csv` を `--undo` に渡せば、すべて元通りになります。

**Q. 一度にたくさんのフォルダを整理できますか？**
A. 対象フォルダを 1 つずつ指定して実行してください（デスクトップ → ダウンロード → 書類…の順など）。

**Q. サブフォルダの中まで整理されますか？**
A. いいえ。指定したフォルダの**直下**にあるファイルだけを整理します。既存のフォルダの中身はそのまま保たれます。
