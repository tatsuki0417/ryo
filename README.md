# ミニゲー祭り 🎮

メイドインワリオ風の、テンポの良いミニゲーム集スマホアプリ（PWA）。
数秒のミニゲームが次々出題され、だんだん加速。ミスするとライフが減り、0でゲームオーバー。**オールジャンル50種類以上＋ボス3種**を収録。

## 特長

- 📱 **PWA** — スマホのブラウザですぐ遊べ、ホーム画面に追加すればアプリのように起動（縦画面 / standalone）。
- ⚡ **テンポの良いコアループ** — 指示表示 → 数秒のミニゲーム → 判定 → 次へ。4問クリアごとにスピードアップ。
- 👾 **ボスゲーム** — 数レベルごとに、長めの手ごたえある1本が出題。
- 🔥 **コンボ** — 連続クリアでコンボ数を表示。ミスでリセット。
- ❤️ **ライフ制** — ハート4つ。失敗で1減、0でゲームオーバー。ハイスコアは端末に保存。
- 🎛️ **タップ + スワイプ操作** — touch / マウス両対応の入力抽象化。
- 🎚️ **ジャンル重み付け出題** — 同じジャンルが連続しないように出題。
- 🔊 **BGM＆多彩な効果音** — WebAudio でプログラム生成（音声アセット不要）。BGMはドラム＋ベース＋メロディのループでレベルごとにテンポアップ。ポップ／コイン／スワイプ／ジャンプ等、動作ごとに違う効果音。右上ボタンで消音。
- ✨ **ジューシーな演出** — タップ／クリアで弾けるパーティクル、クリア時の紙吹雪、ミス／ボスで画面シェイク、コンボで褒め言葉。
- 🧒 **かわいいキャラ** — タイトルやゲーム中にマスコットキャラが登場（子ども〜中高生向け）。

## 開発

```bash
npm install
npm run gen-icons   # PWA アイコンを生成（依存なしのPNGエンコーダ）
npm run dev         # 開発サーバー
npm run build       # 本番ビルド（型チェック + Vite + PWA）
npm run preview     # ビルド結果をプレビュー
```

## 技術構成

- **Vite + React + TypeScript**（`vite-plugin-pwa` で manifest / service worker を生成）。
- 画面遷移（タイトル / プレイ中 / ゲームオーバー）は React、プレイ中は **1枚の Canvas + requestAnimationFrame** が全描画を担当。
- **論理座標系 360×640** で全ミニゲームを実装し、実画面へレターボックス変換（どの端末でも同じ見た目）。

### ディレクトリ

```
src/
  engine/       ゲームエンジン
    types.ts        Microgame インターフェイス / InputEvent 型
    GameEngine.ts   コアループのステートマシン（ライフ/スコア/レベル/制限時間）
    InputManager.ts pointer からタップ/スワイプを検出・正規化
    audio.ts        WebAudio 効果音
    music.ts        WebAudio ループBGM（ドラム/ベース/メロディ、レベルでテンポアップ）
    particles.ts    パーティクル（弾け・紙吹雪）
    util.ts         乱数・座標変換・描画ヘルパ
  microgames/   各ミニゲーム + レジストリ（index.ts）
    base.ts         共通ベースクラス + キャラ描画（drawBuddy）
    boss.ts         ボスゲーム
  components/    GameCanvas（rAFループ）
  ui/           TitleScreen / GameOverScreen / Mascot（マスコットSVG）
```

### ミニゲームの追加方法

1. `src/microgames/` に `Microgame` インターフェイスを実装したクラスを作る。
2. `src/microgames/index.ts` の `MICROGAMES` に1行追加。

これだけで出題ローテーションに加わります。

# PC フォルダ整理ツール

散らかった PC のフォルダを、**削除せず安全に**階層構造へ整理するスクリプトです。
「削除しても良さそう」なファイルは、消さずに新規の `_削除候補` フォルダへまとめます。

## 特徴（安全設計）

- 🚫 **削除は一切しません。** すべて「移動」だけです。
- 👀 **既定はドライラン**（計画を表示するだけ）。`--apply` を付けて初めて実行されます。
- ↩️ **いつでも元に戻せます。** 実行内容は CSV ログに残り、`--undo` で復元できます。
- 📁 **既存の意味のあるフォルダには触りません。** 空フォルダやコピー・旧版らしい名前のフォルダだけを削除候補に回します。

## 事前準備

Python 3 が必要です（多くの Mac には最初から入っています。Windows は
[python.org](https://www.python.org/downloads/) からインストールし、
インストール時に「Add Python to PATH」にチェックを入れてください）。

インストール確認:

```
python3 --version    # Mac / Linux
python --version     # Windows
```

## 使い方

### 手順 1: まず計画を確認（ファイルは動きません）

```
# Windows の例（デスクトップを整理する場合）
python organize_pc_folders.py "C:\Users\ryo\Desktop"

# Mac の例
python3 organize_pc_folders.py ~/Desktop
```

どのファイルがどのフォルダに移動されるか、削除候補が何かが一覧表示されます。

### 手順 2: 問題なければ実行

同じコマンドに `--apply` を付けます。

```
python organize_pc_folders.py "C:\Users\ryo\Desktop" --apply
```

実行が終わると、整理内容を記録した `organize_log_日付_時刻.csv` が対象フォルダ内に作られます。

### 手順 3: 元に戻したいとき

手順 2 で表示されたログファイルを `--undo` に指定します。

```
python organize_pc_folders.py --undo "C:\Users\ryo\Desktop\organize_log_20260706_101530.csv"
```

すべてのファイルが元の場所に戻り、整理で作った空フォルダも片付けられます。

## 整理のルール

### 種類別フォルダへの振り分け

| フォルダ | 対象の例 |
|----------|----------|
| `書類` | pdf, doc, docx, xls, xlsx, ppt, txt, csv など |
| `画像` | jpg, png, gif, heic, svg など |
| `動画` | mp4, mov, avi, mkv など |
| `音声` | mp3, wav, m4a, flac など |
| `圧縮ファイル` | zip, rar, 7z, tar など |
| `アプリ・インストーラ` | exe, msi, dmg, pkg, apk など |
| `コード` | py, js, html, json など |
| `その他` | 上記に当てはまらないもの |

### `_削除候補` フォルダへまとめるもの

- OS が作る不要ファイル（`.DS_Store`, `Thumbs.db`, `desktop.ini` など）
- 一時・未完了ファイル（`.tmp`, `.crdownload`, `~$…` など）
- 中身が空（0 バイト）のファイル
- 内容がまったく同じ**重複ファイル**（1 つだけ残し、残りを移動）
- 「コピー」「バックアップ」「旧」「(1)」などが名前に付いたファイル・フォルダ
- 空のフォルダ

> ⚠️ あくまで「候補」です。中身を確認してから、本当に不要なものだけ手動で削除してください。

## オプション

| オプション | 説明 |
|-----------|------|
| `--apply` | 実際に移動を実行（付けないと計画表示のみ） |
| `--undo <ログCSV>` | 指定した実行を元に戻す |
| `--old-days N` | N 日以上更新のないファイルも削除候補にする（既定 0＝無効） |
| `--include-hidden` | 隠しファイル・ドット始まりのフォルダも対象にする（既定では触りません） |

## よくある質問

**Q. 間違えて実行してしまいました。**
A. 対象フォルダにできた `organize_log_….csv` を `--undo` に渡せば、すべて元通りになります。

**Q. 一度にたくさんのフォルダを整理できますか？**
A. 対象フォルダを 1 つずつ指定して実行してください（デスクトップ → ダウンロード → 書類…の順など）。

**Q. サブフォルダの中まで整理されますか？**
A. いいえ。指定したフォルダの**直下**にあるファイルだけを整理します。既存のフォルダの中身はそのまま保たれます。
