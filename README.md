# マイホムペ 🏠 ― レトロ個人ホームページ製作所

スマホで数分で作れる、2000年代風の"自分だけのホームページ"。
工事中バナー・アクセスカウンター・訪問者ノート・今日の運勢・Web拍手・キラキラ追従カーソル・ピコピコBGM…
懐かしいパーツを**組み合わせて**作る、自己表現サービスのMVPです。

**搭載パーツ**：🚧工事中バナー／🔢アクセスカウンター（キリ番演出）／📖訪問者ノート／
🔮きょうの運勢／👏Web拍手／📢更新履歴／✨キラキラ追従カーソル／🎹ピコピコBGM
**カスタマイズ**：📷プロフィール画像アップ（キラキラ/ハート/シンプルの飾り枠）／
タイトル装飾（虹色/炎/シンプル）／背景テーマ9種（星空・レンガ・チェック・水玉・青空・ノート・さくら・ラメ・マトリックス）

> **なぜこの方向か（市場の狙い）**
> 2026年のネットは「SNS疲れ／アテンション・デトックス」と、
> "2026 is the new 2016" と呼ばれる**懐古回帰**が一等地トレンド。
> ジオシティーズ／前略プロフ世代（今の25〜40歳）に懐かしく、Z世代には逆に新鮮。
> **アルゴリズムのない、やさしい自己表現の場**という現代的な意味も持たせています。
>
> **パクリにしないための線引き**：特定商品のコピーではなく、"あの頃のネット文化"への
> オマージュ。現代のひねり＝①昔は難しかったHTML/FTPが不要で**スマホで簡単に作れる**
> ②**リンクを渡すだけで見せ合える**新しい共有体験。

## 遊び方

1. `index.html` をブラウザで開くだけ（インストール・ビルド不要）。
2. 左の編集パネルでサイト名・自己紹介・背景テーマ・パーツを設定 → 右にリアルタイム反映。
3. `🔗 URLをコピー` で**共有URL**を取得。SNSに貼れば、開いた人にホムペがそのまま見えます。
4. `📷 バナー保存` で、SNS投稿用のレトロバナー画像を保存。
5. `♪ BGM` でピコピコBGMが流れます（音声ファイル不要、その場で生成）。

> ES Modules を使っているので `file://` で開けない環境では簡易サーバー越しに：
> ```
> python3 -m http.server 8000   →  http://localhost:8000
> ```

### ★サーバー0円で共有できる仕組み
ホムペのデータをまるごとURLの `#view=...` に詰め込んでいます。
だから**バックエンドなしでも、リンクを開くだけで相手にページが復元**されます。

## ファイル構成（学習用に役割ごとに分割）

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み（編集パネル＋プレビュー） |
| `css/style.css` | 前半＝操作画面(今どき)／後半＝ホムペ(あえてレトロ) |
| `js/data.js` | ホムペの中身・保存・**URLへの埋め込み/取り出し** |
| `js/themes.js` | 背景テーマ一覧（★課金テーマの起点） |
| `js/render.js` | データ→レトロなページに描く（編集/閲覧で共用） |
| `js/bgm.js` | ピコピコBGM（Web Audio APIで生成） |
| `js/share.js` | 共有URLコピー／SNS用バナー画像 |
| `js/app.js` | 全体をつなぐ（モード判定・編集・カウンター・ノート） |

**改造のヒント**
- テーマを増やす → `js/themes.js` に1行 ＋ `css` に `[data-theme="..."]` の背景
- BGMの曲を変える → `js/bgm.js` の `MELODY`
- パーツを足す → `js/render.js` にHTMLブロックを追加

## ロードマップ

**Phase 1（このMVP）** ✅
ブラウザ完結。作成／プレビュー／URL共有／バナー／BGM。サーバー不要・0円で公開可能。
※ Webリング・訪問者ノートは「この端末内の体験」まで。

**Phase 2 ― 本物の"公開"とつながり**
- 無料バックエンド（Supabase等）で、本物のURLでホムペを公開
- **Webリング**（🔗次のホムペへ→でみんなの家を巡る＝新規流入の主戦力）
- 訪問者ノートを本当の相互機能に／キリ番の記念カキコ文化

**Phase 3 ― 拡張**
- パーツのバリエーション増（限定GIF・BGM・フォント）
- 素材クリエイター経済（ユーザーがパーツを作って売る）

## マネタイズ設計

| 段階 | 手法 | 補足 |
|---|---|---|
| 1. 集客 | 完全無料で作れる | まず拡散最優先 |
| 2. 少額課金 | 限定テーマ・GIF・BGM・フォント（買い切り） | `themes.js` の `premium` が起点 |
| 3. サブスク | 独自URL・広告非表示・容量アップ | 継続課金の柱 |
| 4. 経済圏 | ユーザー製パーツの販売手数料 | 人気が出たら |

まず Phase 1 を公開し、**シェア数・URL経由の訪問・再訪率**を見てから
Phase 2 に投資するのが、個人開発でリスクを抑える進め方です。

## 公開（デプロイ）方法

静的サイトなので無料でそのまま公開できます。
- **GitHub Pages**：Settings → Pages で公開
- **Netlify / Vercel / Cloudflare Pages**：フォルダをドラッグ＆ドロップ

App Store審査が不要なので、**その日のうちに拡散テスト**ができます。
